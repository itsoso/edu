# 社会速查卡：提分最快

## 你的现状

社会从 **80 分** 提到 **95 分** (满分 100)，说明方法对了。现在要做的是**让好成绩稳定**。

## 核心方法

### 1. 框架化记忆

每个单元用**一页纸**画出知识主线。可以是：

- **时间线**（历史类）
- **因果链**（事件为什么发生 → 带来什么影响）
- **概念关系图**（政治、地理概念）

**背诵顺序**：先背框架 → 再填细节 → 最后串联。

### 2. 主观题分点作答

社会大题**最忌写成一大段**。训练自己：

```
① 观点 / 角度 1 ——  具体材料或解释
② 观点 / 角度 2 ——  具体材料或解释
③ 观点 / 角度 3 ——  具体材料或解释
```

每一点都是"**观点 + 材料/解释**"的结构。

### 3. 选择题错了必须回课本

不要看完答案就结束：

- 翻到课本对应段落
- 把原文画出来
- 搞清楚到底错在哪个概念
- 在错题旁写一句总结

### 4. 每天 15 分钟碎片背诵

社会最适合"**少量多次**"，不要攒到考前突击。

推荐时间：

- 早上起床后 5 分钟
- 午休前 5 分钟
- 睡前 5 分钟

## 一周计划

| 天 | 内容 |
|---|---|
| 周一 | 新知识框架图 1 个 |
| 周二 | 背昨天框架图 + 2 道大题 |
| 周三 | 选择题错题回课本 |
| 周四 | 新框架图 + 背 |
| 周五 | 综合复习本周全部 |
| 周末 | 主观题专项 + 真题练习 |

## 目标

- **短期 (4 周)**：稳定 92+
- **中期**：稳定 93~95

## 记住一句话

> **社会是最"努力 = 分数"的科目。**
> **框架要清，分点要齐，细节要背。**
